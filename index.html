🛡️ โซน A — แกนหลัก

🔥 โซน B — หุ้นซิ่ง

เหวี่ยงแรงมาก ส่วนใหญ่ยังไม่มีกำไร ราคาขับเคลื่อนด้วยความคาดหวังและข่าว ขึ้นได้ทีละ 20-50% ในวันเดียว และลงได้เท่ากัน
กติกาที่ควรตั้งกับตัวเอง: เงินที่ใส่โซนนี้ต้องเป็นเงินที่หายทั้งก้อนแล้วยังนอนหลับ และรวมกันไม่ควรเกิน 20-25% ของพอร์ต

ตัวเลือกที่ 1 — Twelve Data (แนะนำ ให้กราฟย้อนหลังยาว)

โควต้าฟรี: 8 ครั้ง/นาที, 800 ครั้ง/วัน — เพียงพอสำหรับใช้ส่วนตัว

สมัครที่ financialmodelingprep.com → Dashboard → คัดลอก API key
โควต้าฟรี: 250 ครั้ง/วัน

key จะถูกเก็บไว้ในเบราว์เซอร์ของคุณเองเท่านั้น (localStorage) ไม่ถูกส่งไปที่ไหนนอกจากผู้ให้บริการข้อมูล

สำรอง / กู้คืนข้อมูล

ข้อมูลทั้งหมดเก็บในเบราว์เซอร์เครื่องนี้ ถ้าล้าง cache ข้อมูลจะหาย แนะนำให้กด Export เก็บไฟล์ไว้เป็นระยะ
ข้อมูลราคาอาจล่าช้า 15 นาทีหรือเป็นราคาปิดวันก่อน ขึ้นกับแพลนฟรีของผู้ให้บริการ
หน้านี้เป็นเครื่องมือติดตามส่วนตัว ไม่ใช่คำแนะนำการลงทุน · การลงทุนมีความเสี่ยง
